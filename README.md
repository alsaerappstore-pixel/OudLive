- ثمانينات نيكل وستيل، تسعينات رقمية، وألفينات زجاجية؛ كل حقبة تعمل مع طرق العرض الثلاث.
- مقابض دوارة لكل قيم المؤثرات ولمبات صغيرة لتشغيل الوحدات. شبكة أصغر للطوابع الخمسة عشر مع فروق أقوى خصوصًا الأصالة والريشة الحادة والنقاء الجاف.
- الكاميرا الأمامية افتراضيًا بأقل تكبير وأوسع مجال مدعوم، ومعاينة وتصدير دون قص الإطار لملء الشاشة.
- بطاقة واحدة لكل تسجيل؛ تشغيل الصوت أو الفيديو، حفظ في الصور، مشاركة، تحديد الكل وحذف المحدد.
