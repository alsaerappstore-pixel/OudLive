# عود لايف 3.13.0 — خانات الإيقاع وتوازن التسجيل

[تحميل IPA](https://github.com/alsaerappstore-pixel/OudLive/actions/runs/37794345657/artifacts/11558511118) — فك ZIP وثبّت OudLive-unsigned.ipa عبر Sideloadly بنفس الحساب السابق.

خمس خانات فوق مكتبة الإيقاعات: اضغط الفارغة للاختيار، والممتلئة للاستدعاء، والنقاط أسفلها للتغيير أو التفريغ أو حفظ الإيقاع الحالي. تُحفظ الخانات والأسماء والمستويات بعد إغلاق التطبيق.

زر السلة بجانب تعديل الاسم يحذف الإيقاع من المكتبة وخانات الحفظ، ويمكن استعادة المحذوفات. يظل الأصل المضمّن دون تعديل.

منزلق صوت الإيقاع مستقل عن منزلق صوت العود. كلاهما يعمل في المعاينة وتسجيل الصوت والفيديو. صفر يكتم القناة؛ 100٪ هو مستوى العود الأصلي، ويمكن رفعه إلى 200٪. حماية الذروة تعمل بعد الجمع. هذا تحكم يدوي في التوازن وليس تسوية تلقائية لجهارة التسجيلات المختلفة.

292 WAV أصلية قابلة للتشغيل و20 RX2 محفوظة غير مدعومة. خيار حفظ الإيقاع مع التسجيل أو الاستماع فقط باقٍ. في الاستماع فقط، استخدم سماعة لمنع تسرب الإيقاع من مكبر الهاتف إلى المايك. تغيير السرعة يغير الحدة أيضًا.
