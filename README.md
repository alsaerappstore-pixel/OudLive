# عود لايف 3.2

**[تحميل IPA الجديد](https://github.com/alsaerappstore-pixel/OudLive/actions/runs/37096326198/artifacts/11263853692)** — فك ZIP وثبّت OudLive-unsigned.ipa عبر Sideloadly بنفس حسابك السابق. التحديث فوق التطبيق يحافظ عادةً على تسجيلاتك؛ لا تحذف التطبيق لاستبداله.

ثلاث واجهات مختلفة: استوديو بمقابض دقيقة، بسيط بأصوات جاهزة بضغطة، ومسرح بمفاتيح مؤثرات كبيرة وإضاءة تتبع الصوت. اختيار الشكل محفوظ ولا يغيّر الصوت. كل الوظائف متاحة في كل شكل، مع مقارنة A/B مؤقتة.

تحت كل تسجيل صوتي أو فيديو في تسجيلاتي زر **حفظ في الصور**. اسمح بالإضافة وانتظر رسالة النجاح. ينسخ الفيديو النهائي بصوت التأثيرات ويحتفظ بالأصل. الصوت يُحفظ في الصور كفيديو بخلفية ثابتة مع كامل التسجيل. تظل المشاركة والحذف بتأكيد متاحين.

تسجيل بالمؤثرات بدون سماعة، مستوى تسجيل مستقل وحماية قمم، و12 طابعًا جاهزًا ووضع مستقل للصوت البشري. يبقى مكبر الآيفون صامتًا أثناء المعالجة بدون سماعة؛ اسمع الملف بعد الحفظ.
