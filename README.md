# عود لايف 3.3

**[تحميل IPA الجديد](https://github.com/alsaerappstore-pixel/OudLive/actions/runs/37203836997/artifacts/11303604329)** — فك ZIP وثبّت OudLive-unsigned.ipa عبر Sideloadly بنفس حسابك وفوق التطبيق الحالي.

15 زرًا داخل صفحة التسجيل، لكل منها مجموعة كاملة من المؤثرات ووصف عربي: الأصالة، ريشة حادّة، نقاء، عمق القاعة، مجلس خشبي، وتر حريري، قرار عميق، بريق زجاجي، رجع خاطف، نبض متكرر، حوار الوادي، وتران، موج ناعم، طيف معدني، وأفق سينمائي.

تُفعّل الأزرار وضع العود والمؤثرات وتحافظ على مستويات المستخدم. تختلف في النبرة والمساحة والإيقاع والحركة. تعمل قبل التسجيل وأثناءه، ولا تغيّر الملفات المسجلة سابقًا. [وصف الطوابع ومراجع البحث وحدود الاختبار](RECORDING_PRESETS_AR.md).

تبقى الأشكال الثلاثة والألوان والهوية باسم ياسر الغامدي، مع تسجيل الصوت والفيديو والحفظ في الصور والمشاركة والحذف. [دليل التسجيل](RECORDING_AR.md) · [الهوية](BRANDING_AR.md) · [الأشكال](THEMES_AR.md) · [التحقق](VERIFICATION_AR.md).

الأصالة مستوحى من التسجيل القديم ولا يحاكي جهازًا بعينه. نقاء لا يزيل ضوضاء الميكروفون. لا يوجد Auto-Tune. تأخير Bluetooth باقٍ، والفيديو يحتاج تجربة التزامن على جهازك. الحد الأدنى iOS 16.
