# عود لايف 3.11 — مؤثرات أقوى ومكسر من ست قنوات

**[تحميل IPA الجديد](https://github.com/alsaerappstore-pixel/OudLive/actions/runs/37678668469/artifacts/11508536730)** — فك ZIP وثبّت OudLive-unsigned.ipa عبر Sideloadly فوق التطبيق الحالي بنفس الحساب.

- توسعة الصدى إلى 100٪ بنطاق علوي أقوى؛ يظل مسموعًا في وضع الاستجابة الحية.
- خفض التشويش ببوابة متدرجة فعالة بين الجمل، مع حساسية ومدى خفض متزايدين.
- ضغط صوت أقوى بتحريك العتبة والنسبة، حتى 8:1 وتخفيض أقصاه 24 dB.
- القناة السادسة «توازن الجهير»: ±9 dB حول 230 Hz، وزر «محايد» لإعادتها إلى الصفر.
- المكسر الفضي واللمبات، أوضاع العود العشرة وصورها، خانات الحفظ والثيمات، التسجيل الصوتي والفيديو والحفظ في الصور باقية. الإيقاعات محذوفة.

ابدأ بتغيير مؤثر واحد. جرب الصدى 50–65٪ والضغط 45–60٪، واضبط خفض التشويش حسب غرفتك؛ هذه نقاط تجربة فقط. الضغط القوي قد يخفض الجهارة، والبوابة القوية قد تقصر ذيل النغمة؛ لا تزيل البوابة ضجيجًا مستمرًا أثناء العزف. مستوى السماعة مستقل عن الملف المحفوظ.
