# عود لايف 2.0

تطبيق iPhone عربي لمعالجة صوت العود والصوت البشري عبر الميكروفون وسماعتك بالبلوتوث أو السلك.

**[تحميل النسخة 2.0 — IPA](https://github.com/alsaerappstore-pixel/OudLive/actions/runs/36604489866/artifacts/11049699765)**

نزّل الحزمة وفكّ الضغط، ثم اختر `OudLive-unsigned.ipa` في Sideloadly واضغط Start بنفس حساب Apple السابق. لا تحذف التطبيق القديم قبل التحديث إذا أردت الحفاظ على إعداداتك.

ابدأ بمستوى خروج منخفض. اختر سماعتك بالبلوتوث من مركز التحكم، ثم افتح التطبيق واختر «قاعة كبيرة». جرّب +6 dB للالتقاط إذا لزم، ثم اضبط قوة المؤثرات حسب ذوقك.

[ما الجديد ولماذا](V2_CHANGES_AR.md) · [دليل التشغيل](README_AR.md) · [نتائج التحقق](VERIFICATION_AR.md) · [البناء](https://github.com/alsaerappstore-pixel/OudLive/actions/runs/36604489866)

تقوية رقمية حتى +30 dB، صدى أطول وتحكم بذيله وبدايته ولمعانه، صدى إيقاعي ستيريو، حماية قمم، ألوان متميزة، حفظ المفضلة وواجهة من ثلاث صفحات. A2DP يستخدم ميكروفون الآيفون؛ لا يُستخدم ميكروفون سماعة البلوتوث، وتأخير البلوتوث باقٍ. Auto-Tune غير متاح.

نجح بناء الجهاز واختبارات الصوت والإعدادات. تجربة جودة الصوت وسماعة المستخدم على النسخة الجديدة ما زالت مطلوبة. ملف IPA غير موقّع؛ يتولى Sideloadly توقيعه. الحد الأدنى iOS 16.
