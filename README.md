# OudLive — عود لايف

تطبيق iPhone عربي لمعالجة صوت العود والصوت البشري مباشرة.

**[تحميل IPA](https://github.com/alsaerappstore-pixel/OudLive/actions/runs/36586931107/artifacts/11041863432)** — فك ضغط التنزيل واسحب `OudLive-unsigned.ipa` إلى Sideloadly.

نجح بناء iPhone arm64 واختبارات DSP. الملف غير موقّع؛ يوقّعه Sideloadly أثناء التثبيت. لم يُختبر التطبيق على iPhone فعلي بعد. يلزم iOS 16 أو أحدث وسماعة سلكية أو واجهة صوت USB. Auto-Tune غير متاح في هذه النسخة.
