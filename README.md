# OudLive — عود لايف

تطبيق iPhone عربي لمعالجة صوت العود والصوت البشري مباشرة.

**[تحميل IPA](https://github.com/alsaerappstore-pixel/OudLive/actions/runs/36600882735/artifacts/11048518606)** — فك ضغط التنزيل واسحب `OudLive-unsigned.ipa` إلى Sideloadly.

[دليل الاستخدام والتثبيت بالعربية](README_AR.md) · [نتائج التحقق](VERIFICATION_AR.md) · [البناء الناجح](https://github.com/alsaerappstore-pixel/OudLive/actions/runs/36600882735)

نجح بناء iPhone arm64 واختبارات DSP. الملف غير موقّع؛ يوقّعه Sideloadly أثناء التثبيت. أكد المستخدم عمل الإصدار 1.0 على جهازه؛ دعم Bluetooth في الإصدار 1.1 لم يُختبر على سماعته بعد. الإصدار 1.1 يدعم سماعة Bluetooth A2DP مع ميكروفون الآيفون، إضافة إلى السلك وUSB. يلزم iOS 16 أو أحدث. Auto-Tune غير متاح في هذه النسخة.
