# عود لايف 3.5 — واجهة معالج العود

**[تحميل IPA الجديد](https://github.com/alsaerappstore-pixel/OudLive/actions/runs/37325294798/artifacts/11351269398)** — فك ZIP ثم ثبّت OudLive-unsigned.ipa عبر Sideloadly بنفس حسابك وفوق التطبيق الحالي.

- لوحة داكنة مستوحاة من المرجع المختار، صورة عود ومقابض ملوّنة ومفاتيح مستقلة للمؤثرات.
- استماع مباشر بالمؤثرات دون تسجيل، مع اختيار مايك الآيفون / USB أو مايك سماعة البلوتوث المتوافقة مع HFP وخروج الصوت فيها.
- زر تسجيل أحمر بقائمة للصوت أو الفيديو؛ معاينة أمامية قبل التسجيل، تبديل الكاميرا ولقطة تحفظ في الصور.
- ترتيب يتكيف مع وضع الآيفون العمودي والأفقي، مع ملفات وإعدادات وتفاصيل للمؤثرات في لوحات مستقلة.
- جميع الطوابع الخمسة عشر والخانات الثماني والمكتبة الموحدة والحفظ والمشاركة والحذف باقية.
- الواجهات والثيمات السابقة متاحة من الإعدادات، ويمكن الرجوع منها إلى الواجهة الجديدة.

[دليل الواجهة](UPDATE_35_AR.md) · [مراجعة التصميم](design-qa.md) · [التحقق](VERIFICATION_AR.md).

الحد الأدنى iOS 16. لا يوجد Auto-Tune أو إيقاف مؤقت للتسجيل. الكاميرا والبلوتوث والحفظ في ألبوم الصور تحتاج تجربة على جهاز حقيقي. التسجيل الصوتي يُحفظ في الصور كفيديو بغلاف ثابت.
