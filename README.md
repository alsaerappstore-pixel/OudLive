# عود لايف 3.9 — إيقاع مباشر وأوضاع مصوّرة

**[تحميل IPA الجديد](https://github.com/alsaerappstore-pixel/OudLive/actions/runs/37640451128/artifacts/11492135964)** — فك ZIP وثبّت OudLive-unsigned.ipa عبر Sideloadly فوق التطبيق الحالي بنفس الحساب.

- عشرة أوضاع عود طبيعية، خمسة أزرار في كل صف، مع صورة مستقلة لكل وضع وصورة رئيسية تتغير عند الاختيار.
- خمسة أوضاع جديدة: Velvet Bass، Clear Studio، Open Courtyard، Tarab Hall، Silk Strings.
- 60 إيقاعًا وتوزيعًا، منها 18 مصريًا و16 خليجيًا و11 يمنيًا. تشمل الوحدة الكبيرة والمقسوم والصعيدي وتنويعاتها.
- اسمع الإيقاع فور تشغيله من الجوال أو السماعة، قبل التسجيل وأثناءه. مستوى الإيقاع مستقل عن كتم مراقبة الميكروفون.
- اختر «حفظ مع التسجيل» لإدراجه في الصوت أو الفيديو، أو «استماع فقط» لاستبعاده من المزيج الرقمي المحفوظ. الاختيار محفوظ وثابت خلال التسجيل.
- واجهة عربية، ثيمات وخانات تخصيص، تسجيل صوت وفيديو، حفظ في الصور، مشاركة وحذف.

عند «استماع فقط» استخدم سماعة لمنع دخول الإيقاع عبر الميكروفون من مكبر الجوال. مراقبة الميكروفون عبر مكبر الجوال مغلقة، لكن الإيقاع يعمل عليه. التأخير اللاسلكي يعتمد على السماعة والنظام.
