# عود لايف 2.3

**[تحميل IPA الجديد](https://github.com/alsaerappstore-pixel/OudLive/actions/runs/36735979690/artifacts/11107515071)** — فك ZIP وثبّت OudLive-unsigned.ipa عبر Sideloadly بنفس حسابك السابق.

تسجيل بالمؤثرات بدون سماعة، مستوى تسجيل مستقل عن السماعة والكتم، مؤشر تسجيل وحماية قمم، ووضع «عود صافي» بنبرة أخف. يستمر تسجيل الصوت والفيديو والحفظ والمشاركة محليًا.

افتح «التسجيل» واضغط ابدأ مباشرة. لا يحتاج Bluetooth. يبقى مكبر الآيفون صامتًا أثناء المعالجة بدون سماعة؛ اسمع الملف بعد الحفظ. جرّب «عود صافي» وابدأ بمستوى التسجيل 0 dB ثم ارفعه حسب المؤشر.

[دليل التسجيل](RECORDING_AR.md) · [الاختبارات](VERIFICATION_AR.md) · [البناء](https://github.com/alsaerappstore-pixel/OudLive/actions/runs/36735979690) · [دليل التشغيل](README_AR.md)

الفيديو تجريبي والتزامن يحتاج اختبارًا على الجهاز. لا يوجد Auto-Tune. السماعات تدعم الاستماع المباشر عند توصيلها، وتأخير Bluetooth باقٍ. الحد الأدنى iOS 16.
