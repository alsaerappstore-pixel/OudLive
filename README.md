# عود لايف 3.12.0 — إيقاعاتي الأصلية

نجح بناء iPhone وفحص الملفات والصوت والمحاكي. [تحميل IPA](https://github.com/alsaerappstore-pixel/OudLive/actions/runs/37760617202/artifacts/11541629473) — فك ZIP وثبّت ملف OudLive-unsigned.ipa عبر Sideloadly بنفس حساب التطبيق الحالي. انظر UPDATE_312_AR.md للتفاصيل.

تفتح «مكتبة إيقاعاتي» جميع الإيقاعات وتتيح البحث وتعديل اسم العرض. شغّل الاستماع المباشر واختر إيقاعًا ثم حدّد «حفظ مع التسجيل» أو «استماع فقط». الخيار يُثبّت أثناء التسجيل. التشغيل مستمر دون تسجيل أيضًا.

292 WAV قابلة للتشغيل، و20 RX2 محفوظة لكنها غير قابلة للتشغيل هنا. لم تُعدّل الملفات الأصلية. تغيير السرعة بين 50 و200٪ يغير سرعة التشغيل والحدة فقط؛ تعيد «الأصل» السرعة إلى 100٪. للإيقاع مستوى مستقل، ولا تمر أصواته في مؤثرات العود.

استخدم سماعة في وضع الاستماع فقط لمنع التقاط الميكروفون للإيقاع من مكبر الهاتف.

تعمل GitHub Actions على macOS لبناء نسخة arm64 غير موقعة وتغليفها في IPA تُوقّع عبر Sideloadly. لا يلزم امتلاك Mac. الإيقاعات تُضمّن داخل التطبيق ولا تحتاج استيرادًا لاحقًا.
