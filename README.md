# عود لايف 2.2

معالجة صوت العود والصوت البشري مع تسجيل الصوت بالتأثيرات وتصوير فيديو عمودي بصوت معالج.

**[تحميل IPA الجديد](https://github.com/alsaerappstore-pixel/OudLive/actions/runs/36693725594/artifacts/11086524501)** — سجّل دخول GitHub وفك ZIP ثم ثبّت OudLive-unsigned.ipa باستخدام Sideloadly بنفس حسابك السابق.

الجديد: صفحة التسجيل، ملفات WAV ستيريو بعد المؤثرات، فيديو 720p مع المسار المعالج، قائمة تسجيلات وتشغيل ومشاركة. [دليل التسجيل](RECORDING_AR.md).

ابدأ العزف بالسماعة أولًا، ثم افتح «التسجيل». اختر صوتًا أو فيديو واضغط ابدأ التسجيل. انتظر تجهيز الفيديو بعد الإيقاف. الكتم ومستوى الخروج يؤثران في التسجيل.

[نتائج الاختبارات](VERIFICATION_AR.md) · [البناء](https://github.com/alsaerappstore-pixel/OudLive/actions/runs/36693725594) · [مفاتيح المؤثرات والأصوات المحفوظة](V21_CHANGES_AR.md)

الفيديو تجريبي: يجب التحقق من الكاميرا وتزامن الصورة والصوت على جهازك. Bluetooth يستخدم ميكروفون الآيفون؛ التأخير في الاستماع باقٍ. لا يتوفر Auto-Tune. التسجيلات محلية ولا تُرفع تلقائيًا. الحد الأدنى iOS 16.
