# عود لايف 3.10 — مكسر الصوت

**[تحميل IPA الجديد](https://github.com/alsaerappstore-pixel/OudLive/actions/runs/37644201949/artifacts/11493097306)** — فك ZIP وثبّت OudLive-unsigned.ipa عبر Sideloadly فوق التطبيق الحالي بنفس الحساب.

- حذف الإيقاعات تمامًا: الواجهة والمحرك والعينات ومسار إضافتها للتسجيل.
- مكسر فضي بخمسة منزلقات عمودية ومقابض سوداء: الصوت، التقاط المايك، الصدى، خفض التشويش، وضاغط الصوت.
- لمبات طولية خضراء وصفراء وحمراء: إشارة حية للمايك والمخرج، ومقدار الضبط للمؤثرات. أزرار تشغيل وإيقاف للمؤثرات الثلاثة.
- المكسر مرتبط بمعالجة الاستماع والتسجيل والإعدادات المحفوظة. منزلق الصوت يضبط السماعة؛ مستوى التسجيل مستقل في صفحة التسجيل.
- الأوضاع العشرة وصورها، خانات الحفظ والثيمات، الصوت والفيديو والحفظ في الصور والمشاركة باقية.
