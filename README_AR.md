# عود لايف — تطبيق iPhone عربي

مشروع أصلي لـ iOS 16 أو أحدث، بواجهة عربية من اليمين إلى اليسار ومعالجة ميكروفون مباشرة على الجهاز. يحتوي على مشروع Xcode جاهز للفتح ومسار GitHub Actions لإخراج IPA من جهاز Windows، دون امتلاك Mac.

**حالة التسليم:** نجح بناء التطبيق بـ Xcode 16.4 على macOS بتاريخ 2026-09-29، وخرج IPA حقيقي لجهاز iPhone arm64. نجحت اختبارات DSP مع AddressSanitizer وUndefinedBehaviorSanitizer وفحص بنية IPA. أكد المستخدم تثبيت وتشغيل الإصدار 1.0. الإصدار 2.0 الخاص بالبلوتوث اجتاز البناء، ويحتاج تجربة سماعة المستخدم.

**[تنزيل حزمة IPA من GitHub](https://github.com/alsaerappstore-pixel/OudLive/actions/runs/36604489866/artifacts/11049699765)** — سجّل الدخول بحسابك، نزّل ZIP وفكّه، ثم استخدم `OudLive-unsigned.ipa` في Sideloadly. نتيجة البناء مرتبطة بالنسخة `0e38dadeb9bc8e42db0a3d1eda2a84a3209d4614`. تنتهي مدة حفظ هذه الحزمة في 2026-10-13؛ يمكن إعادة تشغيل البناء عند الحاجة.

## الموجود في التطبيق

الإصدار 2.0 يعيد تنظيم الواجهة إلى العزف والمؤثرات والتوصيل. أُضيفت تقوية الالتقاط +6 dB، تحكم في طول الصدى حتى 7 ثوانٍ وفاصل بدايته ولمعانه، تعويض الضغط، ضبط الإيقاع بالنقر، والمفضلة. راجع `V2_CHANGES_AR.md`.

- الألوان الجاهزة: طبيعي، كلاسيكي، فخم / ثقيل، حاد، مشكل، قاعة كبيرة. «مشكل» مزيج من الصدى والحركة والتوسيع.
- Reverb ستيريو، Delay بزمن وتكرار قابلين للتعديل، EQ ثلاثي، Compressor، Chorus أو Flanger، وDoubler ستيريو.
- وضع مستقل للصوت البشري مع حفظ إعداداته منفصلة عن العود.
- واجهة عزف مختصرة، زر كتم كبير، تجاوز المؤثرات، مؤشرات مستوى الميكروفون والخروج، اختيار الميكروفون وحفظ الإعدادات.
- طلب مخزن 128 عينة عند 48 kHz، وخيار 256 عينة للاستقرار. النظام قد يختار قيمة أخرى؛ الشاشة تعرض القيمة الفعلية.
- إيقاف عند انقطاع الملحق، المقاطعة أو خطأ الصوت؛ إعادة التشغيل يدويًا. يستمر الصوت في الخلفية أثناء تشغيله.
- لا تسجيل، لا خدمات تحليلات ولا رفع للصوت. جميع الإعدادات محلية.

**Auto‑Tune غير منفذ في هذا الإصدار.** وضع الصوت البشري يستخدم EQ والضغط والمؤثرات، ولا يصحح النغمة. Doubler نسخ مؤخرة ومتحركة زمنيًا، وليس تصحيحًا طبقيًا. يمكن إضافة مصحح نغمة لاحقًا مع اختبار جودة وتأخير فعليين، واختيار سلم موسيقي يدعم متطلبات الغناء العربي.

## إنتاج IPA من Windows

1. فك ضغط الحزمة. أنشئ مستودعًا في حسابك على [GitHub](https://github.com/new)، أو استخدم مستودعًا خصصته لهذا التطبيق.
2. ارفع **محتويات مجلد OudLive** إلى جذر المستودع: يجب أن يظهر `OudLive.xcodeproj` و`OudLive` و`Tests` و`scripts` و`.github` في المستوى الأول، دون مجلد إضافي يغلّفها. يمكن استخدام **Add file → Upload files** من المتصفح.
3. تأكد من وجود `.github/workflows/build-ios.yml`. إن لم يرفعه المتصفح، استخدم **Add file → Create new file**، وأدخل هذا المسار ثم انسخ محتوى الملف المرفق كما هو.
4. افتح **Actions → Build iPhone IPA → Run workflow**. يعمل أيضًا عند رفع الملفات إلى `main` أو `master`. اختر الفرع الذي رفعت إليه الملفات.
5. انتظر نجاح التشغيل باللون الأخضر. افتح التشغيل ثم **Artifacts → OudLive-iPhone-IPA**. نزّل الأرشيف وفكّه؛ الملف المطلوب داخله هو **OudLive-unsigned.ipa**.

البناء يستخدم خادم GitHub بنظام macOS وXcode: لا تحتاج Mac محليًا ولا Apple ID في GitHub. توافر دقائق Actions أو أي تكلفة مرتبط بخطة حسابك؛ راجع إعدادات حسابك قبل تشغيل البناء.

إذا فشل التشغيل، نزّل `OudLive-build-diagnostics` أو أرسل سجل الخطوة الحمراء لإصلاح السبب. تشغيل الاختبارات بمفرده لا يعني أن ملف iOS بُني بنجاح؛ خطوة بناء Xcode يجب أن تنجح أيضًا.

## التثبيت عبر Sideloadly

1. افتح [Sideloadly](https://sideloadly.io/) على Windows ووصل iPhone وافتح قفله. يجب أن يظهر الجهاز في البرنامج.
2. اسحب **OudLive-unsigned.ipa** إلى البرنامج. هذا ملف جهاز arm64 غير موقّع، ومخصص ليوقّعه Sideloadly بحسابك أثناء التثبيت.
3. أدخل Apple ID داخل Sideloadly واتبع التحقق الذي يطلبه. **لا تضع كلمة المرور في المشروع أو GitHub أو المحادثة.**
4. بعد التثبيت، اتبع طلب الثقة بالمطور من إعدادات الجهاز، وفعّل Developer Mode إذا طلبه iOS. قواعد صلاحية التوقيع وتجديده تعتمد على نوع حساب Apple المستخدم؛ راجع [الأسئلة الرسمية](https://sideloadly.io/faq).

هذا المسار لا يحتاج اشتراك Apple Developer مدفوعًا في مرحلة البناء غير الموقّع. التثبيت الفعلي يخضع لقبول Sideloadly وApple للحساب والجهاز؛ لا يمكن التحقق منه دون تشغيل البناء وتجربة الهاتف.

## أول تجربة صوت

1. وصّل سماعة Bluetooth من إعدادات الآيفون واخترها كمخرج صوت من مركز التحكم، أو وصّل سماعة سلكية أو واجهة USB. الإصدار 2.0 يدعم Bluetooth A2DP مع ميكروفون الآيفون افتراضيًا. ميكروفون سماعة البلوتوث ليس مستخدمًا. يوجد زر لاختيار السماعة داخل التطبيق.
2. افتح عود لايف، اضغط **ابدأ العزف** واسمح بالميكروفون.
3. إذا كان الميكروفون المستخدم هو ميكروفون السماعة بدل الآيفون، اختر الميكروفون المطلوب من **توصيل الصوت** ثم أعد التشغيل. تظهر قائمة المداخل بعد تفعيل جلسة الصوت.
4. ابدأ بصوت منخفض، اختر **طبيعي**، ثم زد المستوى تدريجيًا. احرص ألا يظهر مؤشر «عالٍ» عند ضربات الريشة.
5. عند التقطيع: فعّل **استقرار أعلى** ثم أعد التشغيل. عند الصفير من مكبر متصل بواجهة USB: اكتم الصوت وأبعد الميكروفون عن المكبر.

سماعة Bluetooth لا تناسب هدف أقل تأخير في هذه النسخة. زمن المخزن ليس الزمن الكامل من الميكروفون إلى الأذن. الرقم الثاني هو مجموع قيم تأخير الإدخال والإخراج المبلّغ عنها، وليس نتيجة اختبار loopback. المؤثرات الزمنية تضيف الصدى عمدًا؛ المسار الجاف لا يستخدم مخزنًا إضافيًا في خوارزمية المعالجة.

## للمطور

افتح `OudLive.xcodeproj` على Mac واختر مخطط `OudLive`. لا توجد مكتبات طرف ثالث أو CocoaPods أو حزم Swift مطلوبة. عند البناء المحلي لجهاز مباشرة اختر فريق التوقيع ومعرّف حزمة يخصك. لبناء IPA غير موقّع:

```bash
bash scripts/build-ipa.sh
```

المعمارية: SwiftUI ← AudioModel لإدارة AVAudioSession ← جسر Objective‑C++ ← RemoteIO ← معالجة C++ أحادية الإدخال وثنائية الخروج. يفضّل 48 kHz ويستخدم معدل الجهاز المقبول فعليًا. المخازن تُخصّص قبل التشغيل. حلقة الصوت لا تستخدم أقفالًا أو تخصيص ذاكرة أو Swift أو Objective‑C أو إرسالًا للواجهة. التحكم والمعايرة عبر atomics ذات ضمان lock-free على الهدف.

سلسلة المؤثرات: تقوية الإدخال ← إزالة الترددات تحت السمعية ← EQ ← ضغط تدريجي وتعويض مستقل ← مزج الصدى والحركة والتوسيع والمساحة ← كسب الخروج والكتم ← حماية قمم ستيريو مشتركة واستعادة تدريجية. حماية القمم لا تستخدم lookahead إضافيًا، مع قص احتياطي عند 0.98. ينطبق كسب الإدخال والخروج والكتم والحماية حتى في المقارنة بالصوت الأصلي. المؤشر يعرض مستوى الإدخال بعد التقوية الرقمية. التفاصيل والبحث في `V2_CHANGES_AR.md`.

اختبارات DSP المحمولة:

```bash
clang++ -std=c++17 -O1 -g -fsanitize=address,undefined Tests/dsp_tests.cpp -o dsp-tests
./dsp-tests
```

اختبارات الجهاز المطلوبة موضحة في `DEVICE_TESTS_AR.md`. يُرجى عدم إعلان رقم تأخير أو جودة احترافية قبل تنفيذها.
