# عود لايف 3.8 — العود الطبيعي والإيقاعات

**[تحميل IPA الجديد](https://github.com/alsaerappstore-pixel/OudLive/actions/runs/37575197647/artifacts/11462277140)** — فك ZIP وثبّت OudLive-unsigned.ipa عبر Sideloadly فوق التطبيق الحالي بنفس الحساب.

- خمسة أوضاع فقط: Slow Metal، Dry Rhythm، Stone Chamber، Wooden Majlis، Sharp Pick. معالجة طبيعية تحفظ طبقة العود، دون كورس أو فلانجر أو تغيير طبقة.
- موازنة لطيفة، ضغط خفيف، صدى غرف وتأخير دافئ، وانتقال متدرج بين الأوضاع. Slow Metal طابع داكن ودافئ وليس تشويه جيتار.
- وضع Live Low Latency للاستماع الحي. تأخير البلوتوث الفعلي يعتمد على السماعة والنظام.
- ارفع مقبض لوحة المؤثرات أو اضغطه لكشف الضبط السريع. خانات حفظ التخصيصات والثيمات باقية.
- 36 توزيعًا إيقاعيًا في سبع مجموعات إقليمية، مع سرعة 40–220 ومستوى مستقل وضبط السرعة بالنقر. تدخل المصاحبة في تسجيل الصوت والفيديو.
- التسجيل دون سماعة، اختيار الميكروفون، الاستماع قبل التسجيل، والحفظ في الصور باقية.
